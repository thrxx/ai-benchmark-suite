# Описание задач бенчмарка

Проект включает два независимых набора задач: **Coding** (навыки программирования) и **Assistant** (логика, безопасность, креативность). Каждый набор содержит 10 задач с разной сложностью и весом в итоговой оценке.

## 📊 Система оценки

Итоговый балл рассчитывается по формуле взвешенного среднего:
```
Overall Score = Σ(Score_i × Weight_i) / Σ(Weight_i)
```
- **Easy** (1-3): вес `1.0` — базовое следование инструкциям и синтаксису.
- **Medium** (4-6/7): вес `1.5` — алгоритмическое мышление, работа с ограничениями, логика.
- **Hard** (7-10): вес `2.0` — архитектура, безопасность, креативность с жёсткими правилами, production-ready паттерны.

### Интерпретация результатов
| Балл | Уровень | Рекомендация |
|------|---------|--------------|
| `90–100` | 🟢 Production-ready | Подходит для автоматизации и daily-использования |
| `75–89`  | 🟡 Надёжный ассистент | Требует code-review или модерации сложных запросов |
| `60–74`  | 🟠 Требует доработки | Нестабильные результаты, нужен RAG или системные промпты |
| `<60`    | 🔴 Не готов | Высокий риск галлюцинаций, ошибок безопасности или синтаксиса |
