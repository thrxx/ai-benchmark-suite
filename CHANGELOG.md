## [1.0.0] - 2026-04-29

### Добавлено
- **Интерактивный Лаунчер (`launcher.py`)**:
  - Трехступенчатый мастер настройки: выбор провайдера → выбор типа бенчмарка → выбор модели.
  - Автоматическое сканирование доступных моделей через API (Ollama / LM Studio).
  - Автогенерация файла конфигурации `.env` на основе выбора пользователя.
  
- **Benchmark для Кодирования (Coding Benchmark)**:
  - Пакет из **10 задач** различной сложности (Python, JavaScript, SQL, C++, Go).
  - Темы: алгоритмы, работа с памятью, многопоточность, асинхронность, REST API, тестирование.
  - Автоматическая валидация кода через исполнение в песочнице и статический анализ.

- **Benchmark для Ассистентов (Assistant Benchmark)**:
  - Пакет из **10 задач** на логику, понимание контекста, безопасность и креативность.
  - Темы: структурирование данных (JSON/Markdown), поиск ошибок, логические загадки, этические дилеммы, многоязычие.
  - Семантическая проверка ответов (Regex-анализ, проверка фактов, соответствие формату).

- **Инфраструктура и Изоляция**:
  - Запуск всех бенчмарков в изолированном **Docker-контейнере**.
  - Поддержка провайдеров: **Ollama** (native API и OpenAI-compatible) и **LM Studio**.
  - Система взвешенных оценок: Easy (×1.0), Medium (×1.5), Hard (×2.0).
  - Генерация детального отчета в формате JSON (`benchmark_result.json`) с аналитикой и выводами.

### Изменено
- Унифицирована работа с API через класс `Config`, читающий переменные окружения.
- Оптимизированы регулярные выражения в валидаторах (устранены `FutureWarning`).
- Улучшена обработка ошибок сети и таймаутов (четкое разделение ошибок подключения и отсутствия ответа).

### Исправлено
- Исправлена проблема доступа к локальному серверу из Docker-контейнера на Windows/macOS (использование `host.docker.internal` и `extra_hosts`).
- Исправлена передача таймаута из `.env` в HTTP-клиент (ранее использовалось жестко заданное значение).
- Исправлен парсинг JSON-ответов, обернутых в Markdown-блоки (```json ... ```).
- Корректная обработка пустого списка моделей от провайдера (теперь скрипт завершается с понятной ошибкой, а не падает).
